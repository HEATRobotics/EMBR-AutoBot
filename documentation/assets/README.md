# README assets

`heat-robotics-logo.webp` is the HEAT Robotics logo published in the
[UBC engineering team directory](https://experience.apsc.ubc.ca/okanagan/student-groups/design-teams-clubs-and-associations).
It is stored here unchanged for use in this team's README.

`goal-progress.svg` is generated by
[`update_progress.py`](../../scripts/documentation/update_progress.py).
Edit the four completion booleans in
[`progress.json`](../../scripts/documentation/progress.json), then run
`python3 scripts/documentation/update_progress.py` from the repository root.
Do not edit the generated image directly.
